# Estudio Teburu

Landing page de Estudio Teburu (estudio de grabación, producción musical y podcast). React 19 + Vite + React Router 7, estilos con Sass.

## Comandos

- `npm install` — instalar dependencias
- `npm run dev` — servidor de desarrollo
- `npm run build` — build de producción
- `npm run preview` — previsualizar el build localmente
- `npm run lint` — correr ESLint
- `npm run deploy` — publicar el build en GitHub Pages (rama `gh-pages`)
